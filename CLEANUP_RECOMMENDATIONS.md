## Folder Organization Problems

1. Source files are mostly flat at repo root, while `mix_design/` is packaged. More core subsystems should move toward package structure.
2. Generated artifacts live beside source in the working tree, making local scans noisy.
3. Historical docs, active docs, specs, plans, and generated wiki pages are all separate doc surfaces with no clear canonical hierarchy.
4. Root-level tests are inconsistent with `tests/` discovery.

## GitHub Hygiene Recommendations

1. Keep generated artifacts ignored; do not commit `outputs/`, archives, `tmp/`, caches, virtualenvs, `.claude/`, or `.gitnexus/`.
2. Add a `docs/archive/` policy for historical reports/specs.
3. Add a small curated fixture artifact set for dashboard demos instead of committing full runtime outputs.
4. Replace stale status docs with generated-on-demand status or clearly dated historical docs.
5. Require a pre-PR cleanup check: `git status --ignored --short`, `python scripts/run_ci_checks.py`, and a scan for `*_patch.py`, root `test_*.py`, archives, zips, and logs.

## Cleanup Priority Order

1. Fix false-completeness docs and current artifact status docs.
2. Remove local generated/tool residue from the workspace before any GitHub push.
3. Decide fate of `AGENTS.md` and `CLAUDE.md` generated by GitNexus.
4. Archive/delete duplicate docs and stale source-of-truth specs.
5. Move/archive root `test_track_b.py` and Track B config.
6. Retire patch/reference modules.
7. Shrink deprecated wrappers (`search.py`, eventually `design_tool.py`) after moving any real logic.
